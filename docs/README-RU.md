## О вторичной разработке

Этот репозиторий является вторичной разработкой на основе оригинального проекта **[Translumo](https://github.com/ramjke/Translumo)** автора **ramjke** и его участников. Право собственности, авторские права, лицензия и история вкладов оригинального проекта остаются за оригинальным автором и участниками.

В этой версии локальный OCR заменен на распознавание текста по изображению через OpenAI-совместимый AI API. Также добавлены OpenAI-совместимый AI-перевод, китайская локализация, журнал выполнения, диагностика скриншотов, сброс подсказок и одиночный режим выбора области по замороженному скриншоту.

## Основные изменения

- Старые локальные OCR-движки заменены AI-распознаванием текста по изображению.
- Для AI OCR и AI-перевода используются отдельные Base URL, API key, модель, таймаут и подсказки.
- DeepL, Google, Yandex и Papago остаются доступными как ручной выбор текстового переводчика.
- AI-перевод оборачивает исходный текст в `<text>...</text>`, чтобы удаленная модель переводила только нужный фрагмент.
- Непрерывный режим перевода удален. Используйте `Shift+F`, чтобы заморозить экран, выбрать область и один раз выполнить OCR и перевод.
- Последние полные скриншоты и OCR-обрезки сохраняются в `%TEMP%\Translumo\Screenshots` для диагностики.
- В окне настроек есть страница журнала для диагностики захвата, OCR, перевода и API-запросов.

## Использование

1. Запустите Translumo и нажмите `Alt+G`, чтобы открыть настройки.
2. Выберите исходный и целевой языки в настройках языка и перевода.
3. В разделе `AI text recognition` укажите OpenAI-совместимый Base URL, API key и модель OCR.
4. Если выбран переводчик `AI`, настройте `AI translation` с отдельными Base URL, API key и моделью перевода.
5. Когда нужный текст виден на экране, нажмите `Shift+F`.
6. Translumo заморозит экран под курсором, позволит выбрать область на замороженном изображении, затем один раз выполнит OCR и перевод.

## API

- `GET {baseUrl}/models` получает список моделей.
- `POST {baseUrl}/chat/completions` используется для AI OCR и AI-перевода.
- `baseUrl` должен включать путь версии API, например `https://api.example.com/v1`.
- API key отправляется через `Authorization: Bearer {apiKey}`.
- OCR отправляет PNG data URL. Полный base64 изображения в журнал не записывается.

## Сборка

Используйте Visual Studio 2022 с компонентом .NET Desktop Development и .NET 8 SDK, либо выполните:

```powershell
dotnet build Translumo.sln -c Debug
```

## Требования

- Windows 10 version 2004 build 19041 или новее, либо Windows 11.
- GPU с поддержкой DirectX 11.
- Рекомендуется минимум 2 GB RAM.
- Доступный OpenAI-совместимый API-сервис для AI OCR и AI-перевода.
